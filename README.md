# IPL Analytics Dashboard (2008–2024)

An end-to-end data analytics project built using SQL and Power BI.

## Tools Used
- MySQL — data storage and querying
- Power BI — dashboard and DAX modeling
- Dataset — 260,000+ ball-by-ball records (Kaggle)

## Key Insights
- Virat Kohli is the all-time top scorer with 8,000+ runs
- Mumbai Indians have the most match wins (142)
- YS Chahal leads all-time wicket takers (213)
- Season-wise runs show consistent growth from 2008 to 2024

## Dashboard Features
- 5 interactive visuals
- Season slicer to filter all visuals
- Cross-filtering between charts
